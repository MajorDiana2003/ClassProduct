# ClassProduct 🐍

Учебный проект интерактивного каталога продуктов с категориями, созданный в рамках изучения объектно-ориентированного программирования (ООП) на Python.

## 🚀 Стек технологий и зависимости

### Основное окружение:
* **Python** ^3.12 — интерпретатор языка.

### Инструменты разработки и качества кода (Dev-зависимости):
* **Poetry** — современный менеджер пакетов и виртуальных окружений.
* **Pytest** (^8.0.0) — фреймворк для написания и запуска автоматических тестов.
* **Pytest-cov** (^5.0.0) — плагин для анализа и вывода процента покрытия кода тестами.
* **Black** (^24.0.0) — автоматический форматировщик кода (настроен на длину строки 119 символов).
* **Flake8** (^7.0.0) — линтер для статического анализа кода и проверки соответствия PEP 8.
* **Mypy** (^1.8.0) — инструмент для строгой проверки аннотаций типов данных.


## Новые фичи (Домашнее задание 15.1)
* **Инкапсуляция данных:** Списки продуктов (`__products`) и цены (`__price`) сделаны приватными для защиты от прямого изменения извне.
* **Методы-свойства (Getters/Setters):**
  * Геттер `products` в классе `Category` возвращает отформатированный список строк вида: `Название продукта, X руб. Остаток: X шт.`
  * Геттер и сеттер `price` в классе `Product` контролируют изменение стоимости (запрет на цены $\leq 0$ и интерактивное подтверждение снижения цены через `input()`).
* **Фабричные методы:** Реализован метод класса `new_product` для генерации объектов из словаря с автоматическим объединением дубликатов (складывание количества и выбор максимальной цены).
* **Магические методы (`__str__`, `__add__`):**
  * Класс `Product`: реализовано строковое представление в формате `Название продукта, X руб. Остаток: X шт.`, а также метод `__add__` для сложения общей стоимости товаров двух продуктов на складе (с валидацией типов).
  * Класс `Category`: реализовано строковое представление вида `Название категории, количество продуктов: X шт.` (суммирует количество всех единиц товара в категории).
* **Итерирование объектов (`CategoryIterator`):**
  * Создан вспомогательный класс-итератор для поочередного перебора объектов продуктов внутри категории в циклах `for`.
* **Логирование:**
  * Интегрировано логирование ключевых бизнес-процессов: инициализации объектов, добавления продуктов, выполнения арифметических операций и работы итератора.



## 📁 Структура проекта
* `src/models.py` — базовые доменные модели `Product` (продукт) и `Category` (категория) с логированием инициализации.
* `src/utils.py` — утилита для автоматического парсинга исходных данных из формата JSON в объекты классов Python.
* `data/products.json` — исходный файл с данными по категориям и товарам.
* `tests/` — изолированный пакет с автоматическими тестами и фикстурами.
* `main.py` — корневая точка входа для демонстрации работы скрипта.

## 🛠️ Инструкция по развертыванию

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd ClassProduct
   ```

2. **Установите зависимости через Poetry:**
   ```bash
   poetry install
   ```

3. **Запуск проекта:**
   ```bash
   poetry run python main.py
   ```
