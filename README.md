# ClassProduct 🐍

Учебный проект интерактивного каталога продуктов с категориями, созданный в рамках изучения объектно-ориентированного программирования (ООП) на Python.

## 🚀 Стек технологий и зависимости

### Основное окружение:
* **Python** ^3.12 — интерпретатор языка.

### Инструменты разработки и качества кода (Dev-зависимости):
* **Poetry** — современный менеджер пакетов и виртуальных окружений.
* **Pytest** (^8.0.0) — фреймворк для написания и запуска автоматических тестов.
* **Pytest-cov** (^5.0.0) — плагин для анализа и вывода процента покрытия кода тестами.
* **Black** (^24.0.0) — автоматический форматировщик кода (настроен на длину строки 119 символов).
* **Flake8** (^7.0.0) — линтер для статического анализа кода и проверки соответствия PEP 8.
* **Mypy** (^1.8.0) — инструмент для строгой проверки аннотаций типов данных.

## 📁 Структура проекта
* `src/models.py` — базовые доменные модели `Product` (продукт) и `Category` (категория) с логированием инициализации.
* `src/utils.py` — утилита для автоматического парсинга исходных данных из формата JSON в объекты классов Python.
* `data/products.json` — исходный файл с данными по категориям и товарам.
* `tests/` — изолированный пакет с автоматическими тестами и фикстурами.
* `main.py` — корневая точка входа для демонстрации работы скрипта.

## 🛠️ Инструкция по развертыванию

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd ClassProduct
   ```

2. **Установите зависимости через Poetry:**
   ```bash
   poetry install
   ```

3. **Запуск проекта:**
   ```bash
   poetry run python main.py
   ```

## 🧪 Тестирование и контроль качества

* **Запуск тестов и проверка покрытия кода:**
  ```bash
  poetry run pytest
  ```
* **Проверка стиля кода (линтер):**
  ```bash
  poetry run flake8 .
  ```
* **Проверка аннотаций типов:**
  ```bash
  poetry run mypy .
  ```
